Stack Teknologi yang Digunakan

Frontend

Next.js · React

App Router, form generate, history, result viewer, profile, dan admin pages.

Backend

Laravel REST API

Auth, generate flow, history, admin module, AI settings, dan support endpoints.

Database

MongoDB Atlas

Menyimpan user, hasil generate, settings, token request, dan support conversations.

AI Provider

Groq · OpenRouter · Gemini

Provider dipilih dari backend / admin settings sesuai kebutuhan model dan limit.

Rendering Dokumen

React Markdown, Mermaid, dan styling custom untuk result detail.

Testing & Tools

PHP Artisan Test, npm lint, npm build, GitHub, Postman, VS Code.

Deployment Readiness

Panduan deployment untuk frontend, backend, MongoDB, dan environment production sudah tersedia.

Teknologi dipilih agar mudah dipahami, cukup modern, dan tetap realistis untuk project akademik.
