Slide 17 · Testing dan Deployment

Kualitas Teknis, Testing, Repository, dan Deployment

Testing

Backend diuji dengan `php artisan test`.

Frontend diuji dengan `npm run lint` dan `npm run build`.

Tersedia `docs/TESTING_CHECKLIST.md` untuk validasi fitur utama dan admin.

Checklist mencakup generate, history, profile, admin, support chat, dan responsive UI.

Deployment Readiness

Frontend siap dipasang ke Vercel / platform serupa.

Backend Laravel dipisah agar mudah di-host secara mandiri.

Panduan deployment dan environment sudah disiapkan pada docs.

API key aman karena disimpan di backend `.env`, bukan di frontend.

Repository

Monorepo tersusun dalam folder `frontend-next`, `backend-laravel`, `docs`, dan `screenshot`.

Dokumentasi

README, user guide, API documentation, deployment guide, dan demo script tersedia.

Demo Layak UTS

Project menyiapkan web app fungsional, fitur AI nyata, dokumentasi, dan alur presentasi yang jelas.

Slide ini menjawab aspek penilaian technical implementation, dokumentasi, dan kesiapan demo.
