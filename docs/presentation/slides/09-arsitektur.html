Arsitektur Sistem VibePlan AI

User / Admin
Browser desktop atau mobile untuk form, history, result, dan panel admin.

Next.js Frontend
Menangani UI, validasi input, tampilan hasil, dan pengalaman pengguna.

Laravel Backend API
Menangani auth, validasi, prompt orchestration, admin operations, dan storage.

Lapisan Data

MongoDB Atlas

Menyimpan hasil generate AI dan `markdown_content`.

Menyimpan user, history, token request, support chat, dan setting admin.

Mendukung pembukaan ulang result detail dan download Markdown.

Lapisan AI

Provider AI dikonfigurasi di backend

Backend menyusun prompt sesuai mode generate dan policy quality gate.

Provider dan model dapat diganti tanpa membocorkan API key ke frontend.

Fallback model menjaga proses generate tetap stabil saat provider utama bermasalah.

Prinsip 01

Frontend fokus pada pengalaman pengguna dan navigasi workspace.

Prinsip 02

Backend fokus pada logika bisnis, keamanan, dan integrasi AI.

Prinsip 03

Database menjadi pusat penyimpanan hasil generate dan operasional sistem.

Prinsip 04

Pemisahan layer membuat aplikasi lebih aman, maintainable, dan mudah dipresentasikan.

Arsitektur dipisah agar maintainable, aman, dan mudah dijelaskan saat presentasi.
