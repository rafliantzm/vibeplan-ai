Demo Berjalan

Tersedia halaman generate, history, result, profile, admin dashboard, dan live chat support.

Source Code & Dokumentasi

Repository dipisah jelas menjadi frontend, backend, docs, dan screenshot. README serta docs tersedia.

Penilaian Teknis

Project menjelaskan problem solving, AI integration, technical implementation, testing, dan deployment.
