Alur dari Ide Project sampai Dokumen Siap Pakai

1

User mengisi brief project.

Form memuat nama project, ide, target user, masalah utama, app type, tech stack, dan catatan awal.

2

Frontend mengirim request ke backend.

Request dikirim sesuai mode: PRD Generator, Next Step Planner, atau Coding Prompt Generator.

3

Backend menyusun prompt dan memanggil AI.

Backend mengelola model, provider, validasi, fallback, dan response handling.

4

Hasil dikembalikan, disimpan, dan bisa diunduh.

Dokumen tampil di result page, masuk history, dan dapat diunduh sebagai Markdown.
